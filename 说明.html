📄 文件转换工具集 DOCX ↔ PDF ↔ JPG

基于 LibreOffice、Poppler-utils 和 ImageMagick 的交互式转换工具， 支持批量或单次文档 / 图片格式转换，专为 Linux 环境设计。

📁 文件说明

  • 🐍 软件下载.py
  • 🐍 文件转换器(shell).py

软件下载.py — 交互式依赖安装程序，支持一键安装 LibreOffice、Poppler-utils 和 ImageMagick，并提供跨平台（Windows/Linux）下载 LibreOffice 安装包的功能（通过 wget 获取官方镜像）。

文件转换器(shell).py — 核心转换工具，支持三种转换模式：

  • DOCX → PDF（基于 LibreOffice 无头模式）
  • PDF → JPG（基于 pdftoppm）
  • JPG → PDF（基于 ImageMagick 的 convert）

⚙️ 系统要求

  • 操作系统：Linux（脚本使用 apt-get 和 sudo，建议 Ubuntu/Debian 系）
  • Python 版本：Python 3.x
  • 依赖工具（脚本会自动检测，但需手动安装）：
    • libreoffice（用于 DOCX → PDF）
    • poppler-utils（提供 pdftoppm，用于 PDF → JPG）
    • imagemagick（提供 convert，用于 JPG → PDF）

📦 安装与配置

1. 克隆或下载脚本

将两个 .py 文件保存到本地同一目录，并赋予执行权限（可选）：

chmod +x 软件下载.py 文件转换器\(shell\).py

2. 安装依赖（推荐使用 软件下载.py）

运行依赖安装脚本：

python3 软件下载.py

根据菜单提示选择：

  • 1 → 安装 LibreOffice
  • 2 → 安装 Poppler-utils
  • 3 → 安装 ImageMagick
  • 5 → 跨平台下载 LibreOffice 安装包（Windows .msi 或 Linux .tar.gz）
⚠️ 注意： 安装操作需要 sudo 权限，请确保当前用户有 sudo 权限或在 root 下执行。

3. 手动安装（备选）

如果无法使用脚本，也可通过包管理器单独安装：

sudo apt-get update
            sudo apt-get install libreoffice poppler-utils imagemagick

🚀 使用方法

运行转换器

python3 文件转换器\(shell\).py

交互步骤

  1. 程序会显示欢迎信息并提示输入要转换的文件路径（绝对或相对路径）。
  2. 输入转换后的文件路径（包括文件名和扩展名，例如 ./output.pdf）。
  3. 选择转换类型（输入数字）：
    • 1 → DOCX → PDF
    • 2 → PDF → JPG（注意：输出路径应为图片前缀，实际会生成 前缀-1.jpg、前缀-2.jpg 等）
    • 3 → JPG → PDF
    • 4 → 退出程序

示例

请输入要转换的文件路径：/home/user/document.docx
请输入转换后的文件路径：/home/user/output.pdf
请你选择要转换的文件类型：
1.docx=>pdf
2.pdf=>jpg
3.jpg=>pdf
4.quit
请输入选项编号：1
程序将调用 LibreOffice 进行转换，并输出完成提示。

❓ 常见问题

Q：转换 PDF 到 JPG 时，输出文件数量较多，如何控制？

A：pdftoppm 默认每页生成一个 JPG 文件，输出文件名为“你指定的前缀-页码.jpg”。目前脚本未提供额外参数，如需调整（如分辨率、质量），可自行修改脚本中的 os.system 调用。

Q：ImageMagick 转换 JPG 到 PDF 时出现权限错误？

A：ImageMagick 的 policy 可能限制 PDF 操作，可编辑 /etc/ImageMagick-6/policy.xml，将 <policy domain="coder" rights="none" pattern="PDF" /> 改为 read|write 或注释掉。

Q：脚本是否支持 Windows/macOS？

A：目前仅针对 Linux（Debian/Ubuntu）优化，apt-get 和 sudo 不适用于其他系统。但你可以使用“跨平台下载”功能获取 LibreOffice 安装包，自行在其他系统安装后，再手动运行转换部分（需调整命令）。

📌 注意事项

  • 输入文件路径和输出路径请勿包含空格，否则可能因命令行解析出错（可考虑用引号包裹，脚本中已做处理）。
  • 转换 DOCX → PDF 时，LibreOffice 会生成与输入文件同名的 PDF 到指定输出目录，输出文件名会被忽略，实际 PDF 名称与输入文件一致。建议在转换后将文件移动/重命名。
  • PDF → JPG 转换会生成多个图片，输出路径应是一个前缀，而非完整图片文件名。

🧑‍💻 开发者说明

  • 脚本使用纯 Python 标准库（os, sys, time），无第三方依赖。
  • 打字机效果函数 type() 仅用于提升交互体验，不影响核心功能。
  • 所有转换命令通过 os.system() 调用系统工具，请确保工具已正确安装。
